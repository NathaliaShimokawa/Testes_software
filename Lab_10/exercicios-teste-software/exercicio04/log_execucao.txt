ARQUITETURA PAGE OBJECT MODEL
------------------------------

pages/base_page.py:
Classe BasePage implementada
   → Inicialização do WebDriver
   → Métodos genéricos: wait_for_element, click, type_text
   → Tratamento de exceções Selenium
   → Utilidades de navegação

pages/google_page.py:
Classe GooglePage implementada
   → Herda de BasePage
   → Localizadores: SEARCH_BOX, SEARCH_BUTTON, RESULTS
   → Métodos: navigate(), search(), has_results(), get_results_count()
   → Encapsulamento completo da interface do Google

tests/conftest.py:
Fixtures Selenium configuradas
   → chrome_driver: WebDriver configurado com opções otimizadas
   → chrome_options: Argumentos para modo headless e performance
   → delay_between_web_tests: Estabilidade entre testes
   → Configurações de timeout e implicit wait

BENEFÍCIOS DO PAGE OBJECT MODEL IMPLEMENTADO
---------------------------------------------
Separação de Responsabilidades: Lógica da página separada dos testes
Reutilização: Métodos das pages usados em múltiplos testes
Manutenibilidade: Mudanças na UI requerem alteração apenas nas Page Classes
Legibilidade: Testes expressam intenções de negócio claramente
Redução de Duplicação: Eliminação de código repetitivo entre testes

CONFIGURAÇÕES SELENIUM IMPLEMENTADAS
------------------------------------
WebDriver Manager: Instalação automática do ChromeDriver
Modo Headless: Execução em background para CI/CD
Timeouts Configurados: implicit_wait (10s), page_load_timeout (30s)  
Opções Otimizadas: --no-sandbox, --disable-gpu, --disable-images
Cleanup Automático: driver.quit() após cada teste
Resolução Fixa: --window-size=1920,1080 para consistência
