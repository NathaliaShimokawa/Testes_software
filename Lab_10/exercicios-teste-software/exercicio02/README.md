# Exercício 02 - Testes de API REST

## Cenários Testados

### 1. Testes de Produtos (Fake Store API)
- **GET**: Listar todos os produtos
- **GET**: Buscar produto específico por ID
- **POST**: Criar novo produto
- **PUT**: Atualizar produto existente
- **DELETE**: Remover produto
- **Error Handling**: Produto não encontrado (404)

### 2. Validações Implementadas
- Status codes esperados (200, 201, 404)
- Estrutura do JSON response
- Tipos de dados dos campos
- Presença de campos obrigatórios
- Performance de response time
